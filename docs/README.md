## Research Context

GraphCeylon-API is a research project focused on creating an intelligent tourism platform for Sri Lanka. The system combines:

- **Multilingual Support**: Sinhala, Tamil, and English
- **Knowledge Graphs**: Structured tourism knowledge
- **AI Recommendations**: Personalized and sustainable tourism suggestions
- **Microservices Architecture**: Scalable and maintainable design
